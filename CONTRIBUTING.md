# Taking part

The sessions run on one private app with one experimenter, so the data itself only comes from there. Everything around it is open.

- **Questions, ideas, your own analysis:** start a thread in [Discussions](../../discussions). If you publish something that uses the data, post a link there too.
- **An experiment you'd like to see:** open an issue with the [experiment form](../../issues/new?template=experiment.yml). Good proposals say what question they answer, and what changes from the sessions already here.
- **Something wrong in the data:** use the [data form](../../issues/new?template=data-problem.yml) with the session id and the file. If it's personal data that shouldn't be public, say where it is without repeating it, and it will be removed.
- **Improving the scripts:** pull requests to `scripts/` are welcome. Run `python3 scripts/research.py check` before opening one. Files in `data/`, `charts/` and the tables in `README.md` are generated, so changes to them by hand are overwritten; fix the script instead.

Reports are written by the experimenter. If you think a report gets something wrong, open an issue: corrections are made in place and noted in [`CHANGELOG.md`](CHANGELOG.md).
